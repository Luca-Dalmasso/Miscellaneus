# BASH
Collection of scripts written in Bash.

# MARKDOWN
Advanced usage of Markdown for software documentation. In this examples, you can find some useful examples of Markdown, PlantUML integration and other useful examples that can be used for documenting any kind of repo.

# TCL
Tcl is widely used for electronic design as is the main interface with EDA Tools. Here i plan to add Tcl scripts / procedures specifically made for ASIC design purposes.

# C
Here I add code related Algorithms & Data Structures.

# ASM
Collection of programs written in ARM or x86 assembly for didactical purposes. Most of this code comes from Computer Architecture classes. 

# VIM
Vim, GCC and a Terminal is all you need to develop low-level software. This is my personal Vim setup.
